# Разрез Новосергеевский — корпоративный сайт

Одностраничный сайт компании АО «Разрез Новосергеевский» (добыча и экспорт угля Кузбасса). Статическая вёрстка, без сборки: достаточно `index.html` и папки `images/`. Подходит для деплоя на [Vercel](https://vercel.com) как Static Site.

## Состав

- `index.html` — вся вёрстка, стили и скрипты в одном файле. Внешняя зависимость только [Google Fonts](https://fonts.google.com) (Unbounded + Manrope, с кириллицей).
- `images/` — фотографии:
  - `hero-truck.jpg` — самосвал на разрезе (герой)
  - `coal.jpg` — крупный план угля
  - `rail.jpg` — полувагоны, вид сверху
  - `port.jpg` — погрузка в трюм судна
  - `engineers.jpg` — специалисты на фоне разреза
  - `office.jpg` — офис / логистика

Пока часть исходных фотографий не получена, в `images/` лежат временные графитовые заглушки с теми же именами и пропорциями. Их достаточно заменить файлами с теми же именами.

## Как обновить фотографии

Исходники кладутся в `/workspace/novosergeevsky-src-photos/`:

- `hero-truck.png`
- `rail.jpg`
- `port.jpg`
- `engineers.png`
- `office.png`
- `coal.png` (необязательно, уже обработан)

Затем из корня `/workspace`:

```bash
./swap-photos.sh
```

Скрипт уменьшает снимки (герой и панорама — до 2000 px по ширине, остальные — до 1400 px), сохраняет качественный progressive JPEG и пропускает отсутствующие файлы.

## Язык

Переключатель RU/EN в шапке меняет весь текст, подписи к фото, `lang`, `title` и описание. Выбор запоминается в `localStorage` (ключ `lang`). По умолчанию — русский.

## Локальный просмотр

```bash
cd novosergeevsky-site
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.
